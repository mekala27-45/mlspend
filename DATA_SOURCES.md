# Source terms and provenance

Project code is Apache-2.0. That license does not replace the terms of third-party source data. Azure Retail Prices API records are public Microsoft pricing material; AWS Price List files are public AWS pricing material. GitHub Actions and repository metadata retain GitHub API terms and each source repository license. Model and hosting prices retain their provider terms. Links, retrieval dates and raw SHA-256 digests are recorded in data/prices and data/portfolio.

Sources: https://prices.azure.com/api/retail/prices ; https://aws.amazon.com/aws-cost-management/aws-price-list-api/ ; https://docs.github.com/en/billing/reference/actions-runner-pricing ; https://developers.openai.com/api/docs/pricing.md ; https://vercel.com/docs/pricing/serverless-functions .

No employer data, customer bills, private prompts or private provider invoices were used. Public portfolio usage is measured; prices are shadow equivalents. Unknown prices are not zero. A retrieved price snapshot applied to the simulated calendar is not a historical price series. FOCUS specification material and validator code retain the FinOps Foundation project licenses.
