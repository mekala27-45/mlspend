# Keep evaluation truth outside method inputs

Date: 2026-11-01. Status: accepted.

## Context and decision

Methods consume validated observations. Only evaluation opens sealed owners, incident schedules and counterfactual costs. Register windows and thresholds before scoring the independent replication, and disclose the earlier study that was already known.

## Alternatives and consequences

Rejected: embedding incident labels or true waste in the feature mart. The import boundary and separate files are an auditable guard, not an operating-system sandbox; production research should separate processes and permissions.

## Evidence

Read the corresponding method in packages/, evaluation/v2/plan.json, and the generated report in docs/methods/. Changes to this decision must preserve earlier registrations and promoted evidence.
