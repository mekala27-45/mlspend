# Use Shapley as a capacity reference

Date: 2026-11-01. Status: accepted.

## Context and decision

Enumerate all coalitions of the registered teams using the registered peak-capacity cost model. Normalize the exact contributions to the recorded shared bill for a comparable allocation. Use usage as the method of record because it is inspectable at the charge level.

## Alternatives and consequences

Rejected: billing directly from standalone coalition capacity costs, which compares a different population to the invoice; and declaring Shapley objectively fair. Different coalition models encode different values.

## Evidence

Read the corresponding method in packages/, evaluation/v2/plan.json, and the generated report in docs/methods/. Changes to this decision must preserve earlier registrations and promoted evidence.
