# Optional MLSpend extension

The v0.1.0 release remains the required, verified product. The optional extension is developed on `stretch-v0.2`, under a separate registered plan. Earlier platform results are already known. This extension makes no new confirmatory statistical claim.

The second price observation is due December 1, 2026. A comparison before that date does not satisfy the month-later requirement. Candidate prices must remain separate from the released price locks.

GPU sharing assumes identical work and quality without interference. The carbon estimate covers modeled GPU electricity with a stated regional grid proxy and PUE assumptions. Missing energy components stay unknown. Budget admission reserves money in an isolated simulation and cannot launch a training job.

The Readback integration consumes public files through a digest lock and catalog. Release and container hardening must preserve the existing public API and the immutable v0.1.0 tag.

Implementation and verification are in progress. The baseline checklist does not imply these optional items are complete.
